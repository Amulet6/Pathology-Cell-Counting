\subsubsection{方向 B：Count Anything 式密集辅助分支}

\paragraph{改进动机。}
对应表~\ref{tab:opt-overview}中的``高密度小细胞漏检（少计）''失败模式。基线 APGCC 在
BCData 和 CoNIC 上都表现出不同程度的少计，其中 BCData 测试集总预测数比真实值低
$3.67\%$，CoNIC 低 $3.08\%$；进一步查看困难样本可发现，漏检主要集中在局部高密度、
细胞尺寸较小且相互靠近的区域。其根本原因在于 APGCC 主要依赖点级匹配监督，能够直接约束
``某个位置是否存在中心点''，但对``一片局部区域整体上是否足够密集''这一连续结构信息利用不足。

方向 B 因此借鉴 Count Anything 一类方法中的密集辅助监督思路，在不改变 APGCC 最终出点逻辑的前提下，
额外引入一个仅在训练阶段使用的 dense auxiliary branch。该分支通过连续的像素级密度响应监督，
引导中层特征更加关注细胞聚集区和小细胞区域，希望优先改善高密度区域的召回能力，并验证
``增加密集监督是否能缓解 APGCC 的局部漏检''这一判断。

进一步分析 APGCC 的误差来源可以发现，其主分支采用查询点分类与点回归联合训练，监督信号主要集中在
少量匹配成功的正样本位置上。对于密集小细胞区域，若某些真实细胞一开始没有被主分支稳定匹配到，
它们几乎无法再从周围区域获得额外的连续监督；相反，模型更容易只学到``少数高置信中心点''，
从而在整体上偏向保守预测。方向 B 的出发点就是补上这部分``区域级、连续型''监督，使网络不仅知道
哪些离散点应当被检测出来，还知道这些点周围本应存在一片更强的密集响应。

\paragraph{方法设计。}
本方向最终采用 \textbf{dense loss-only} 方案。具体做法如下：
\begin{enumerate}
    \item 在 APGCC 编码器的中间层特征上新增一个轻量的 dense head，由若干卷积层输出单通道
    dense map；
    \item 利用现有细胞中心点标注，在训练时将每个 GT 中心渲染为二维高斯响应，并叠加形成
    稠密监督图；
    \item 对 dense head 的输出做 sigmoid 后，与高斯监督图计算均方误差损失（MSE），记为
    $L_{\text{dense}}$；
    \item 训练总损失在原有 APGCC 点分类损失和点回归损失基础上，额外加入一项
    $0.1 \cdot L_{\text{dense}}$；
    \item 测试阶段完全移除 dense 分支，仍只保留 APGCC 原始主分支输出，不做 dense 候选点与主分支的融合。
\end{enumerate}

因此，方向 B 采用``训练期增加连续密集监督、测试期保持原有推理接口''的方式，让模型在学习阶段获得更强的
局部密集结构感知能力，同时避免引入额外推理开销和融合不稳定性。

从实现角度看，dense head 接在编码器的中层特征上。这样可以同时保留较好的局部纹理细节和一定的语义信息，
更适合表达病理图像中``小目标成团出现''的空间结构。监督图的构造方式为：
对每个真实细胞中心 $(x_i,y_i)$ 生成一个二维高斯核
\[
G_i(x,y)=\exp\left(-\frac{(x-x_i)^2+(y-y_i)^2}{2\sigma^2}\right),
\]
并将所有中心的高斯响应叠加为最终的 dense target。实验中固定 $\sigma=2.0$，兼顾了细胞中心附近的局部聚焦能力
与一定范围内的连续平滑性。这样生成的监督图主要强调``哪里存在细胞聚集趋势''。

设 dense head 的预测为 $\hat{D}$，对应的监督图为 $D$，则辅助损失写为
\[
L_{\text{dense}}=\mathrm{MSE}(\sigma(\hat{D}),D),
\]
其中 $\sigma(\cdot)$ 表示 sigmoid。最终训练目标可写为
\[
L=L_{\text{ce}}+\lambda_p L_{\text{point}}+\lambda_d L_{\text{dense}},
\]
其中 $\lambda_p$ 延续 baseline 的点回归权重设置，$\lambda_d=0.1$ 为 dense 辅助损失权重。
这样做的目的是让 dense 分支作为一个相对温和的结构先验，对主分支形成辅助约束。

\paragraph{实验设置。}
方向 B 以 APGCC 的官方微调配置作为统一基线，主干网络为 VGG16-bn + IFI decoder，
均从 ShanghaiTech Part A 预训练权重初始化。三数据集均保持与 baseline 完全一致的训练设置，
只额外打开 dense 分支和 $L_{\text{dense}}$，以确保改进前后可直接比较。具体地：
\begin{enumerate}
    \item BCData 与 MoNuSeg 使用 $256\times256$ crop，CoNIC 使用 $128\times128$ crop；
    \item 三个数据集的 batch size 均为 $8$，训练轮数均为 $200$，学习率为 $5\times10^{-5}$，
    backbone 学习率为 $5\times10^{-6}$；
    \item dense 分支配置为 \texttt{DENSE\_AUX\_EN=True}、\texttt{DENSE\_AUX\_LEVEL=3}、
    \texttt{DENSE\_SIGMA=2.0}，损失权重为 \texttt{loss\_dense=0.1}；
    \item 评测口径与全组统一：计数指标报告 MAE/MSE，定位指标报告 Precision、Recall、
    F1@6/12/24px，其中正文主表采用 F1@12px 作为主要定位指标。
\end{enumerate}

这里特别强调两点控制变量。第一，dense 分支之外的网络结构、数据划分、训练轮数、增强方式、
阈值和评测脚本全部保持不变，因此结果差异可以主要归因于 dense 辅助监督本身。第二，方向 B 的对比重点放在
``是否增加 dense 监督''上；baseline 与 dense loss-only 的差别只发生在训练阶段，
这使得该消融具有较清晰的因果解释。

\paragraph{消融结果分析。}
表~\ref{tab:B-main} 表明，dense loss-only 在不同数据集上呈现出明显的条件性收益。

第一，\textbf{BCData 上收益最明确}。加入 dense 辅助监督后，MAE 由 $18.27$ 降至 $17.51$，
MSE 由 $563.06$ 降至 $548.04$，Precision/Recall/F1@12 也同步提升到
$0.8381/0.8116/0.8247$。这说明在 BCData 这种输入尺寸较大、crop 覆盖区域较完整、
但局部仍存在密集重叠细胞的场景中，连续密集监督确实能够帮助模型补回一部分漏检中心点。

第二，\textbf{MoNuSeg 上只有小幅提升}。其 MAE 从 $111.71$ 降到 $110.36$，
F1@12 从 $0.8032$ 升至 $0.8101$，Recall@12 也从 $0.8970$ 升至 $0.9035$，
说明 dense 分支对跨器官 H\&E 大图中的局部结构表达有一定帮助，但提升幅度不大。
这与 MoNuSeg 本身的主要矛盾并不完全是``少计''有关；该数据集更明显的问题是整体过计和跨器官形态差异，
因此方向 B 只能提供有限修正。

第三，\textbf{CoNIC 上 dense loss-only 不适合作为最终方案}。虽然 Precision@12 和 F1@12
分别从 $0.8070/0.7944$ 提升到 $0.8310/0.8005$，说明定位匹配略有改善，但 MAE 从 $11.99$
恶化到 $13.69$，MSE 从 $389.60$ 上升到 $523.92$，总预测偏差也由 $-3.08\%$ 恶化为 $-7.10\%$，
表现为更严重的欠计数。也就是说，dense 监督在 CoNIC 上提高了部分预测点的置信度与几何对齐，
但没有真正缓解密集小核场景中的整体漏检，反而使模型更保守。

这一结果说明，dense 辅助监督更接近于一种``局部结构正则化''。在 BCData 上，
细胞虽然有重叠，但图像分辨率较高、crop 较大、局部细胞结构相对完整，dense 分支能够给主干提供稳定的区域密集先验；
在 MoNuSeg 上，这种先验仍有一定帮助，但由于主要误差来自过计而非漏计，收益被明显削弱；而在 CoNIC 上，
图像块更小、细胞核更密且外观差异更复杂，单一高斯密集监督不足以准确描述真实分布，最终出现了
``定位略好但整体计数更差''的现象。这也说明方向 B 的效果依赖于数据集的尺度、
crop 大小和主要失败模式。

\paragraph{关于 dense 候选融合的取舍。}
除 dense loss-only 外，我们还尝试过把 dense 分支进一步用于测试期候选融合。但在已有消融中，
dense 候选融合没有带来稳定收益，反而在 BCData 上出现了明显退化：MAE 约为 $18.80$，
F1@12 下降到 $0.7632$，显著差于 baseline 和 dense loss-only。说明 dense 分支一旦直接介入
测试期候选生成或结果融合，容易破坏 APGCC 原有主分支的点预测稳定性。因此本方向最终保留
``仅训练期辅助、测试期剥离''的 dense loss-only 方案，不继续采用融合版本。

造成该现象的原因在于，dense map 本质上描述的是连续区域响应，APGCC 主分支输出的是离散中心点集合，
二者在表示层面并不完全一致。如果在测试阶段将 dense 响应峰值转换为候选点，或者与主分支预测做启发式融合，
很容易引入额外的伪峰值、重复点或阈值敏感问题。综合现有结果看，dense 分支更适合作为
``训练时塑造特征分布''的辅助模块。当 dense 分支只参与训练时，
它能够带来稳定或至少温和的正则化收益；一旦深入介入测试期后处理，收益反而迅速消失。

\paragraph{结论。}
方向 B 的主要结论可以概括为三点。第一，向 APGCC 中加入 Count Anything 风格的连续密集辅助监督是可行的，
且不会改变原有推理接口。第二，dense loss-only 在 BCData 上带来了最稳定、最完整的增益，
在 MoNuSeg 上有小幅正收益，但在 CoNIC 上未改善计数误差，因此它未表现出跨数据集统一最优的特性。
第三，dense 分支更适合作为训练期特征引导，而不适合作为测试期候选融合模块。综合稳定性与实现复杂度，
本方向最终采用 dense loss-only 作为正式版本，并将其定位为一种
``对中等密度和较完整局部结构场景更有效''的辅助监督改进。

从课程设计的角度看，方向 B 的贡献不在于取得了全数据集最优结果，而在于较清楚地回答了一个具体问题：
``为 APGCC 增加 Count Anything 式连续密集监督，是否能缓解密集区域漏检？''实验表明，答案是
``在部分数据集上可以，但收益具有明显条件性''。这一结论本身对后续改进具有参考价值：如果数据集的主要问题是
中高密度区域中的局部漏检，dense loss-only 是一种低风险、低侵入的辅助改进；如果数据集的主要问题是
极小目标、极密集 patch 或复杂形态差异，则还需要结合更强的结构建模或匹配校准策略，单独依赖 dense 辅助监督并不足够。
