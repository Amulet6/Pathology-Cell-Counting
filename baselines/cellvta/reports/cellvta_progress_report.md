# CellVTA 阶段性进展汇报

截至 2026-06-15，CellVTA 在 CoNIC 和 MoNuSeg 上的复现、统一增强训练、中心点评估和效率测试都已完成，当前可以进入与组内其他模型的统一对比阶段。之所以将原先的 CellViT 复现任务切换为 CellVTA，是因为 CellVTA 是在 CellViT 基础上进一步改进得到的，同时这条任务线的论文时间更近、数据和任务设置也更符合老师当前的要求，因此更适合作为当前阶段的复现基线。

## 1. 已完成工作

- 完成 CoNIC 官方复现版本的推理与评估，确认模型和官方推理链路可正常运行。
- 完成 CoNIC 统一数据增强版本的训练、中心点评估和效率测试。
- 完成 MoNuSeg 统一数据增强版本的训练、中心点评估和效率测试。
- 将 CellVTA 的输出适配到统一的中心点评估脚本中，并与 `evaluation/formats/predictions_json.md` 对齐。
- 将效率测试统一到同一套规范下，保证不同模型之间的参数量、FLOPs 和推理时间可直接比较。

## 3. 结果分析

### 3.1 论文复现是否对齐

CoNIC 这部分需要区分“论文文件里的指标”和“我们这次复现跑出来的指标”。两者对应如下：

| 指标 | 论文文件结果 | 我们复现结果 |
| --- | ---: | ---: |
| bPQ | 0.6745 | 0.6594 |
| mPQ | 0.5379 | 0.5408 |
| detection F1 | 0.8721 | 0.8721 |

从结果上看，`detection F1` 与论文文件完全一致，但 `bPQ` 和 `mPQ` 存在轻微差异，说明这次复现与论文结果高度对齐。因此，可以把它作为有效复现和后续比较基线。

## 4. 目前结论

1. 这次复现任务已经从 CellViT 切换为 CellVTA，且 CellVTA 是在 CellViT 基础上的改进版本，更符合当前老师对任务和时间线的要求。
2. CoNIC 的官方复现链路已经跑通，但和论文文件的指标属于基本对齐而非逐项完全一致。
3. CoNIC 统一增强版本和 MoNuSeg 统一增强版本也已经完成，后续可以直接用于组内统一比较。
4. 统一的中心点评估和效率评估脚本已经跑通，后续可以直接用于和组内其他 5 个模型做公平比较。
